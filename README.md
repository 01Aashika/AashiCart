# 🛍️ AashiCart – Modern E-Commerce Website

AashiCart is a modern and responsive e-commerce web application built using React.js and CSS3. It provides an interactive online shopping experience with product browsing, search, wishlist, shopping cart, and checkout interfaces.

## ✨ Features

- 🛒 **Product Catalog** – Browse products across Men, Women, and Kids categories.
- 🔍 **Product Search** – Search products with instant results.
- ❤️ **Wishlist** – Add and manage favorite products.
- 🛍️ **Shopping Cart** – Add, remove, and update product quantities.
- 📦 **Product Details** – View product information and related products.
- 👤 **Login & Signup UI** – Interactive authentication interface with form validation.
- 💳 **Checkout Interface** – Shipping details, payment form, and order confirmation UI.
- 📱 **Responsive Design** – User-friendly shopping interface.

## 🛠️ Tech Stack

| Technology | Purpose |

## 🚀 Getting Started

### Prerequisites

- Node.js
- npm
- Visual Studio Code

### Installation

1. Clone the repository:

```bash
git clone https://github.com/01Aashika/AashiCart.git
```

2. Navigate to the project directory:

```bash
cd AashiCart
```

3. Install dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```

5. Open the local URL displayed in your terminal.

## 🏗️ Build for Production

```bash
npm run build
```
